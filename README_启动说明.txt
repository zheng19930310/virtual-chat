========================================
虚拟社交聊天工具 - 一键启动指南
========================================

⚠️ 您的系统需要先安装 Java 和 Maven 才能运行此项目

📋 最简单的安装步骤（3步完成）：

第1步：安装环境
----------------
右键点击 "install_env.ps1" 文件
选择 "以管理员身份运行"
等待自动安装完成（约5-10分钟）


第2步：验证安装
----------------
关闭当前窗口，打开新的 PowerShell
输入以下命令验证：

    java -version
    mvn -version

如果都显示版本信息，说明成功！✅


第3步：启动项目
----------------
在 PowerShell 中运行：

    cd d:\aiwork\virtual-chat
    .\start.bat

或者双击运行 start.bat 文件


🌐 访问应用
----------------
启动成功后，浏览器打开：
http://localhost:8080
