# 思维链模式 data: 前缀和空白显示问题

**问题发现时间**: 2026-05-09  
**优先级**: 高  
**状态**: 待修复（下次迭代）

---

## 问题描述

思维链内容和最终回答中仍然显示 "data:" 前缀和空白行，影响用户体验。

### 具体表现

1. **思维链内容中显示 "data:"**
   - 每行内容前都有 "data:" 字样
   - 示例：`data:让我来分析这个问题...`

2. **思维链内容中显示空白 "data:" 行**
   - 某些地方显示单独的 "data:"（后面没有内容）
   - 示例：`data:` 独占一行

3. **最终回答中也显示 "data:" 和空白**
   - 回答内容开头有 "data:"
   - 回答末尾有单独的 "data:" 行

## 问题分析

### 当前清理逻辑的问题

虽然之前添加了 data: 前缀清理逻辑，但存在以下问题：

1. **正则表达式不够完善**
   - 当前使用：`replace(/^data:\s*/g, '')`
   - 问题：`^` 只匹配字符串开头，而不是每行开头
   - 结果：只能清理第一个 data:，无法清理后续的

2. **空白 "data:" 行没有被过滤**
   - 当 chunk 只包含 "data:" 而没有实际内容时
   - 清理后变成空字符串
   - 但仍然被追加到内容中

3. **多行内容的处理**
   - 如果 chunk 包含多行，只有第一行会被清理
   - 后续的 "data:" 行仍然存在

### 根本原因

Spring Boot SSE 格式：
```
data:实际内容\n
data:\n
data:另一行内容\n
```

前端接收到的原始数据：
```
data:让我来分析这个问题...
data:
data:首先，用户再次提出...
```

当前处理方式：
- `data:让我来分析这个问题...` → `让我来分析这个问题...` ✅
- `data:` → `` (空字符串，但仍然被追加) ❌
- `data:首先，用户再次提出...` → `首先，用户再次提出...` ✅（但需要多行匹配）

## 待修复方案

### 方案1：改进正则表达式（推荐）

```javascript
// 使用 m 标志（multiline）让 ^ 匹配每行开头
let cleanContent = markerBuffer.replace(/^data:\s*/gm, '');

// 过滤掉空白行
cleanContent = cleanContent.split('\n').filter(line => line.trim() !== '').join('\n');
```

### 方案2：逐行处理

```javascript
let lines = markerBuffer.split('\n');
let cleanLines = [];
for (let line of lines) {
    let cleanLine = line.replace(/^data:\s*/, '');
    if (cleanLine.trim() !== '') {
        cleanLines.push(cleanLine);
    }
}
let cleanBuffer = cleanLines.join('\n');
```

### 方案3：使用更强大的正则

```javascript
// 清理所有 data: 前缀，并移除连续的空白行
let cleanBuffer = markerBuffer
    .replace(/^data:\s*/gm, '')  // 清理每行的 data:
    .replace(/\n{2,}/g, '\n')    // 合并连续的空白行
    .trim();                      // 去除首尾空白
```
